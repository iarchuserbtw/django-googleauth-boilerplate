# Adding an API Endpoint

When adding an endpoint:

1. Determine whether authentication is required.
2. Define request/response validation.
3. Keep HTTP handling in the view.
4. Put reusable business logic in services.
5. Add URL routing.
6. Add OpenAPI documentation.
7. Add tests.
8. Run the full test suite.
9. Run Ruff.
10. Update README/API documentation if public behavior changed.

Do not consider the endpoint complete until tests pass.
